Componenta continua si eliminarea ei

REZULTAT
Da, semnalul prezinta o componenta continua.
Media celor 18288 esantioane este 138.95811461067368.
Dupa centrare, media calculata numeric este -6.3656672040099966e-15, adica

Modulul componentei FFT de la frecventa zero, impartit la N, devine
5.8186176786653873e-15.

JUSTIFICARE MATEMATICA
Componenta continua a semnalului discret este media:
media = (1/N) * suma pentru n=0,...,N-1 din x[n].
La frecventa zero, factorul exponential din DFT este 1, deci:
X[0] = suma x[n] = N*media.
Cum media nu este zero, semnalul are componenta continua.

O eliminam prin formula:
y[n] = x[n] - media.
Atunci suma y[n] = suma x[n] - N*media = 0, deci media lui y este 0.
In domeniul Fourier obtinem Y[0] = 0, iar Y[k] = X[k] pentru k diferit de 0,
in aritmetica exacta. In calculele numerice pot ramane erori foarte mici.

INTERPRETARE
Vectorul centrat y descrie abaterile fata de media intregii inregistrari.
O valoare negativa inseamna trafic sub aceasta medie; nu inseamna un
numar negativ de masini.

si oscilatiile semnalului raman; centrarea nu elimina tendinta.
